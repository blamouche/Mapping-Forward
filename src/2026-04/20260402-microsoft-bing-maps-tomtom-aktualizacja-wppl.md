## Elevator pitch
Microsoft completed the global deployment of TomTom Orbis Maps address data in Bing Maps after a nine-month phased rollout, improving coverage, accuracy, and freshness across Bing Search, Copilot, and Azure Maps.

## Takeaways
- Microsoft completed a nine-month phased global rollout of TomTom Orbis Maps address data in Bing Maps, starting from key European markets
- The Orbis Maps dataset uses the Overture Maps Foundation common standard, combining OSM, partner data, sensor observations, and TomTom's own resources
- Microsoft benchmarked new data against existing data on coverage, query success rate, and positional accuracy before each regional go-live
- The rollout extended to Bing Search, Copilot, and Azure Maps — covering multiple Microsoft location experiences
- Microsoft and TomTom will continue collaboration to add additional Orbis data layers and further improve address quality

## Synthesis
Microsoft has closed out the global deployment of TomTom Orbis Maps address data in Bing Maps, completing a nine-month rollout that began in June 2025. The article from Polish technology publication WP Tech describes the scope and methodology of this significant infrastructure update to Microsoft's mapping and location services.

The new address layer is based on TomTom Orbis Maps, a dataset aligned with the common map standard co-developed by partners of the Overture Maps Foundation. The data draws from multiple sources: Overture's own datasets, OpenStreetMap, commercial partner contributions, sensor observations, and TomTom's proprietary geographic information. This multi-source approach underpins the freshness and accuracy benefits Microsoft is highlighting.

Microsoft's deployment methodology was deliberately incremental. Rather than a global swap, the company added and indexed addresses region by region, then evaluated the new data against the incumbent dataset on three specific metrics: address coverage, query response success rate, and positional accuracy. Only data that met or exceeded quality standards moved to production. Europe was the first target market, chosen for the density and completeness gains it offered, before expansion to other regions.

The deployment is now fully global for the base address layer, bringing measurable improvements to multiple Microsoft services. Bing Maps users see improved address resolution and positional accuracy; Bing Search and Copilot benefit from the same underlying data quality gains; and Azure Maps API customers receive more accurate and complete results from map queries.

Microsoft confirmed that the work with TomTom continues beyond this initial phase. Additional Orbis data layers are planned for integration, and ongoing address quality refinements are expected as the partnership deepens.
