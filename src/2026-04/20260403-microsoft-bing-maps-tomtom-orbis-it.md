# Microsoft Bing Maps si aggiorna con i dati TomTom Orbis Maps
**Source**: https://www.hdblog.it/microsoft/articoli/n653899/microsoft-bing-maps-aggiornamento-tomtom-orbis/
**Date**: 2026-04-03
**Author**: HDblog.it
**Keywords**: Microsoft, Bing Maps, TomTom Orbis, dati indirizzi, Overture Maps Foundation, Azure Maps

## Elevator pitch
Microsoft completa il rollout globale dei dati TomTom Orbis Maps in Bing Maps con il più grande aggiornamento degli indirizzi degli ultimi anni, migliorando la qualità delle ricerche in Bing, Copilot e Azure Maps.

## Takeaways
- Microsoft ha completato il deployment mondiale dei dati di indirizzo TomTom Orbis Maps in Bing Maps
- Il rollout è durato nove mesi, partendo dall'Europa nel giugno 2025
- TomTom Orbis si basa sullo standard Overture Maps Foundation, combinando OpenStreetMap, dati partner e TomTom
- Approccio graduale per regione con validazione della qualità prima della messa in produzione
- Miglioramenti visibili in Bing Maps, Bing Search, Copilot e Azure Maps API

## Synthesis
HDblog.it riporta il completamento da parte di Microsoft dell'integrazione globale dei dati di indirizzo TomTom Orbis Maps in Bing Maps. Questo rappresenta il più significativo aggiornamento dei dati di indirizzo per il servizio di mappe di Microsoft degli ultimi anni, frutto di una partnership strategica approfondita tra le due società.

Il completamento del rollout ha richiesto nove mesi: avviato in Europa nel giugno 2025, è stato progressivamente esteso fino a coprire tutte le regioni mondiali. La scelta di un approccio graduale riflette la complessità dell'operazione — sostituire dati cartografici fondamentali in un servizio utilizzato da milioni di utenti e sviluppatori richiede una validazione attenta per evitare regressioni nella qualità.

TomTom Orbis Maps è costruito sullo standard della Overture Maps Foundation, un'iniziativa open mapping sostenuta da Amazon, Meta, Microsoft e TomTom. Il dataset aggrega OpenStreetMap, dati di partner industriali e le osservazioni proprietarie di TomTom, risultando in una copertura degli indirizzi più ricca e costantemente aggiornata rispetto ai tradizionali database cartografici.

Uno degli aspetti più rilevanti di questo aggiornamento è il modello di aggiornamento continuo: invece di aggiornamenti periodici in blocco, TomTom Orbis utilizza tecniche AI per mantenere i dati aggiornati in modo continuativo, riflettendo i cambiamenti del mondo reale con maggiore tempestività.

Per gli utenti finali, il beneficio è immediato: ricerche di indirizzi più accurate in Bing Maps e Bing Search, risposte più precise del Copilot per domande legate alla localizzazione, e un geocoding migliorato per gli sviluppatori che utilizzano le API Azure Maps.

Dal punto di vista dell'industria cartografica, questo rollout valida il modello dati della Overture Maps Foundation: uno standard aperto che aggrega sorgenti multiple sta dimostrandosi adeguato per alimentare servizi di mappe di scala enterprise, confermando la viabilità commerciale di approcci cooperativi alla produzione di dati geografici fondazionali.
