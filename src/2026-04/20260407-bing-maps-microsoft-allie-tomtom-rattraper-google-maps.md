# Bing Maps : Microsoft s’allie à TomTom pour rattraper Google Maps
**Source**: https://www.01net.com/actualites/bing-maps-microsoft-allie-tomtom-rattraper-google-maps.html
**Date**: 2026-04-07
**Author**: 01net Editorial
**Keywords**: Bing Maps, Microsoft, TomTom Orbis, Copilot, Azure Maps, Overture Maps Foundation

## Elevator pitch
Microsoft has completed a global migration of Bing Maps address data to TomTom Orbis, aiming to improve location accuracy across Bing, Copilot, and Azure Maps as it narrows the gap with Google Maps.

## Takeaways
- Microsoft finished a nine-month global migration of Bing Maps address data to TomTom Orbis
- TomTom Orbis combines Overture Maps, OpenStreetMap, partner datasets, and TomTom sensor data
- The rollout was validated region by region before production deployment
- Address quality improvements affect Bing Maps, Bing Search, Copilot, and Azure Maps APIs
- The move shows Microsoft leaning on open mapping standards to strengthen its location stack

## Synthesis
Microsoft has completed a major refresh of Bing Maps by migrating most of its address data to TomTom Orbis Maps after a nine-month phased deployment. The article frames the change as more than a backend maintenance job: it is presented as a foundational upgrade that should improve how Microsoft resolves addresses across Bing Maps, Bing Search, Copilot, and Azure Maps. In practical terms, the company is trying to make local search and geocoding less error-prone while reinforcing its broader mapping infrastructure.

TomTom Orbis is built as a shared, continuously updated mapping layer that combines inputs from the Overture Maps Foundation, OpenStreetMap, third-party partners, and TomTom’s own sensors. That matters because Microsoft is not simply licensing a static database. It is plugging Bing Maps into a data model designed to absorb frequent real-world changes, which should improve coverage and positional accuracy over time. The use of Overture is also strategically important: Microsoft is betting that open standards can support large-scale commercial mapping products rather than relying entirely on a closed proprietary stack.

The article emphasizes the care taken during migration. Microsoft reportedly rolled out the new address base region by region, starting in Europe where Orbis already offered strong data density. Each geography was compared against the previous base before going live, which suggests the team treated address accuracy as a measurable operational issue rather than a cosmetic enhancement. The Belgrade example cited in the piece illustrates the point: a search that previously landed users at the wrong building now resolves to the precise address.

The competitive angle is also clear. Microsoft is still far behind Google Maps in user mindshare, but better underlying data strengthens every product that depends on location intelligence inside the Microsoft ecosystem. The article argues that Copilot may be the biggest winner because local queries become more useful when addresses and points of interest are more reliable. In that sense, the Orbis migration is not only about catching up in mapping. It is also about giving Microsoft’s AI and cloud products a more trustworthy spatial foundation.
