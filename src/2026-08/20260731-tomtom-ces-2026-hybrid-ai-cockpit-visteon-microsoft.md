# Terugblik TomTom op CES 2026: een hybride AI-tactiek voor de cockpit

**Date**: 2026-07-31
**Author**: WINMAG Pro
**Keywords**: TomTom, CES 2026, hybrid AI, Visteon, Microsoft Azure, cockpit, VLM, agentic AI, Orbis Maps, MCP Server

## Elevator pitch
TomTom unveiled a hybrid AI strategy at CES 2026, combining on-device Vision Language Models with Visteon and cloud-based LLMs via Microsoft Azure, plus an MCP Server for developer integration and Immersive Mapping for automated driving.

## Takeaways
- TomTom's hybrid AI model pairs Visteon's cognitoAI platform for local, privacy-first voice processing with Microsoft Azure OpenAI for cloud-based LLM intelligence.
- The TomTom UX Library enables OEMs to build branded navigation experiences in "weeks instead of months" using pre-integrated Azure services (Cosmos DB, Kubernetes).
- A new TomTom MCP Server (Model Context Protocol) exposes real-time traffic data, location info, and analytics to external AI agents.
- "Agentic AI" marks the shift from simple voice commands to proactive navigation agents that understand context and predict driver needs.
- Orbis for Automated Driving combines intelligent maps with Unity-powered 3D visualization and lane-level guidance for ADAS systems.

## Synthesis
At CES 2026, TomTom presented a comprehensive hybrid AI strategy for the automotive cockpit that bridges on-device and cloud processing. The approach addresses a fundamental tension in automotive AI: vehicles need the intelligence of large language models but cannot depend solely on cloud connectivity due to latency, privacy, and reliability concerns.

The on-device side leverages Visteon's cognitoAI platform with Vision Language Models (VLMs) running directly on automotive hardware. This enables offline, privacy-first voice control without cloud latency—critical for safety-critical navigation interactions. The cloud side integrates Microsoft Azure OpenAI, Azure Cosmos DB, and Azure Kubernetes Service, providing scalable LLM intelligence and rapid update cycles.

A standout announcement is the TomTom MCP Server, implementing the Model Context Protocol to bridge real-time traffic and location data to external AI agents and LLMs. This positions TomTom as a data provider within the broader AI agent ecosystem, not just a navigation vendor. Developers can now plug TomTom's real-time data streams directly into their AI workflows.

The "Agentic AI" concept represents the next evolution beyond voice assistants. TomTom's AI Agent works proactively—understanding driving context, predicting needs, and offering multi-step navigation solutions. This is powered by a multi-agent architecture that connects in-vehicle platforms with real-time traffic data to transform raw data into actionable insights.

For automated driving, TomTom demonstrated "Orbis for Automated Driving" with Immersive Driving Environments. By combining intelligent maps with Unity's rendering engine and lane-level intelligence, ADAS systems gain a precise visual understanding of the road—curves, roadside objects, speed limits—all visualized in rich 3D. The TomTom Orbis Maps platform accelerates map creation and updating, supporting the increasingly detailed map layers required for lane-level guidance.
