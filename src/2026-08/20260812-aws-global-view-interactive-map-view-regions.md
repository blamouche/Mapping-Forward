# AWS Global View Now Offers Interactive Map View for Regions and Local Zones
**Source**: https://aws.amazon.com/about-aws/whats-new/2026/08/aws-global-view-map-view/
**Date**: 2026-08-12
**Author**: AWS
**Keywords**: AWS, interactive map, cloud infrastructure, AWS Regions, Local Zones, infrastructure planning, management console

## Elevator pitch
AWS has added an interactive map view to AWS Global View in the Management Console, letting customers visually explore all AWS Regions and Local Zones on a map instead of scanning a list, simplifying global infrastructure planning.

## Takeaways
- AWS Global View now includes an interactive map view alongside the existing list view
- All AWS Regions and Local Zones are plotted on an interactive map
- Customers can toggle between map and list views for exploring global infrastructure
- Helps visualize already-enabled locations and the full range of available locations at a glance
- Available across all public AWS Regions
- Designed to support informed infrastructure planning decisions

## Synthesis
Amazon Web Services has introduced an interactive map view to AWS Global View, enhancing the way customers explore and plan their global cloud infrastructure footprint. Previously, users had to navigate through a text-based list of AWS locations. The new capability adds a geographic visualization layer where all AWS Regions and AWS Local Zones appear as points on an interactive map within the AWS Management Console.

The map view serves both exploratory and planning purposes. Customers can see which AWS locations they have already enabled in their account alongside the complete catalog of available locations, all within a single visual interface. This side-by-side geographic representation makes it easier to assess regional coverage, proximity to end users, and compliance with data residency requirements. Users can freely toggle between the interactive map and the original list view depending on their workflow.

The feature is available across all public AWS Regions and can be accessed from the Regions and Zones page in the AWS Global View console. For organizations operating multi-region architectures or planning expansion into new geographic areas, the map view provides a more intuitive starting point than scrolling through alphabetical lists, particularly as AWS continues to expand its global footprint with new Regions and Local Zones.
