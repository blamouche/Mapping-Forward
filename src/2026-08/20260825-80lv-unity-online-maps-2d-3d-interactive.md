## Synthesis
Infinity Code has released Online Maps v5, a comprehensive Unity asset pack that brings interactive 2D and 3D mapping capabilities to game developers. The pack allows creation of fully customizable maps for mobile, desktop, WebGL, AR/VR, UI, or in-scene 3D experiences using a single flexible framework. At its core, the tool integrates elevation data from major providers including HERE, Mapbox, MapTiler, and TomTom, enabling developers to build maps with terrain on flat surfaces or as an interactive globe.

The asset pack distinguishes itself through its broad provider support: 16+ map sources with 88+ map types, covering Google Maps, Mapbox, ArcGIS, Nokia Maps, Bing Maps, OpenStreetMap, and many others. It supports both raster and vector tiles, including customizable Mapbox and MapTiler vector maps. Developers can place 2D, 3D, billboard, or custom markers with built-in clustering, and display maps anywhere — on UI, in a scene, or drawn into a texture.

Technically, the pack is compatible with all Unity render pipelines (Built-in, URP, HDRP, Custom RP) and targets standalone, Android, iOS, Windows Store, and WebGL platforms. The inclusion of complete source code with no dependencies means developers can modify or extend any component. A powerful caching system handles raster and vector tiles, elevations, and custom data, while support for WMS, WMTS, custom styles, and multilingual maps adds further flexibility. The pack is currently available at a 50% discount, making it an accessible option for indie and professional game developers alike.
