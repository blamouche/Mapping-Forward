# Google Maps on Android Auto Tests Darker Theme to Reduce Night Glare
**Source**: https://fr.softonic.com/articles/google-maps-sur-android-auto-teste-un-theme-plus-sombre-moins-deblouissement-la-nuit
**Date**: 2026-09-02
**Author**: Softonic
**Keywords**: Google Maps, Android Auto, dark theme, night driving, UI, beta

## Elevator pitch
Google is testing a darker interface for Google Maps on Android Auto in beta version 17.6.663424, aiming to reduce screen glare and driver eye strain during night driving.

## Synthesis
Google is currently testing a darker theme for Google Maps on Android Auto, available in the beta version 17.6.663424. The update addresses a well-known problem: standard dark mode on navigation apps can still produce too much light at night, causing glare that distracts drivers and reduces visibility. The new interface goes further than the existing dark mode by using deeper blacks and reduced brightness across UI elements.

The testing approach follows Google's typical pattern of rolling out interface changes first to beta users before wider release. Night driving safety is an active concern for the automotive navigation segment, and this update aligns with broader industry efforts to optimize in-car displays for low-light conditions. The feature is expected to reach the stable channel in a forthcoming update.
