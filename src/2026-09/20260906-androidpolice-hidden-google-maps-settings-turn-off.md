# 3 Hidden Google Maps Settings You Should Turn Off Right Away

**Source**: https://www.androidpolice.com/google-maps-hidden-settings-turn-off/
**Date**: 2026-09-06
**Author**: Akshay Bhalla, Android Police
**Keywords**: Google Maps, privacy, location tracking, background location, offline maps, personalized ads, visual search, settings, Android

## Elevator pitch
Android Police identifies three Google Maps settings — background location tracking, automatic offline map downloads over cellular, and personalized ads based on visual search — that users should disable for privacy, battery life, and data conservation.

## Takeaways
- Background location/Timeline tracking logs every location visited, duration, and route, and is enabled by default
- Automatic offline map downloads over cellular data drain battery, fill storage, and consume mobile data unnecessarily
- Google Maps serves personalized ads based on location, search history, and visual searches, pulling data from YouTube and Search
- Timeline tracking can be set to auto-delete after 3 months as a compromise
- Offline map downloads should be restricted to Wi-Fi only via Settings > Offline Maps > gear icon

## Synthesis
Google Maps has become an indispensable navigation tool since its launch in the mid-2000s, but several default settings raise privacy and resource concerns that many users overlook. Android Police identifies three settings that should be disabled immediately.

The first is background location and Timeline tracking. Enabled by default, this feature logs every location visited, how long the user stayed, and every route taken daily. While Google moved Timeline data storage to the device, the continuous collection remains a privacy liability — especially if a phone is lost or stolen. The setting is buried deep in the menu: Profile Icon > Your Timeline > Location & privacy settings > Timeline > Turn off. As a compromise, users can set auto-deletion to 3 months instead of fully disabling the feature.

The second setting concerns offline maps. While keeping offline maps updated is recommended, Google Maps auto-downloads updates and recommended maps over cellular data by default. This drains battery, fills storage, and consumes mobile data. Users should change the download preference to Wi-Fi only via Profile > Offline Maps > gear icon, and disable both auto-update and auto-download of recommended maps.

The third issue is personalized ads. Google Maps uses location, activity, and visual search data to serve ads within the navigation app, including Promoted Pins. These ads pull data from other Google services like YouTube and Search. Disabling them requires navigating to the Google Account's Data & Privacy section, selecting Web & App Activity, and unchecking "Include Visual Search History." This setting is linked to the main Google account rather than the Maps app itself, making it harder to find.
