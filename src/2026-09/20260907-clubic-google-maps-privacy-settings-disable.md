# Google Maps: Disable These Settings to Protect Your Privacy and Battery

**Source**: https://www.clubic.com/actualite-628483-google-maps-desactivez-ces-reglages-pour-proteger-votre-vie-privee-et-votre-batterie.html
**Date**: 2026-09-07
**Author**: Mia Ogouchi, Clubic
**Keywords**: Google Maps, privacy, battery, settings, Timeline, incognito mode, offline maps, data protection, location history

## Elevator pitch
Clubic details three key Google Maps settings to disable for better privacy and battery life: turning off Timeline location history, enabling incognito navigation mode, and restricting offline map auto-updates to Wi-Fi only.

## Takeaways
- Google Maps' Timeline feature records every trip, stop, and route by default, storing data on the device
- Users can disable Timeline or set auto-deletion after 3 months instead of permanent recording
- Incognito mode suspends location history recording, search tracking, and personalized recommendations
- Offline maps auto-update by default over both Wi-Fi and cellular data, draining battery and consuming mobile data
- Users can restrict offline map downloads to Wi-Fi only and disable auto-updates in Settings
- All three settings are accessible through the profile photo menu in Google Maps

## Synthesis
Google Maps activates several settings by default that can compromise privacy and drain battery life. Clubic identifies three key settings that users should consider adjusting.

The first is the Timeline feature, which records every trip, the duration of stops, and visited locations by default. This data is stored on the device, consuming storage space and presenting a security risk if the phone is lost or stolen. Users can disable Timeline entirely via the profile photo menu, or alternatively set auto-deletion after 3 months to retain recent travel history while limiting data accumulation.

The second setting is incognito navigation mode, which suspends location history recording, search tracking, and personalized recommendations. Accessible through the profile photo menu by selecting "Turn on private navigation mode," this feature ensures certain trips remain private. When enabled, Google Maps stops recording trips and searches and no longer personalizes recommendations based on activity.

The third concerns offline maps, which auto-update by default over both Wi-Fi and cellular connections. This can drain battery and consume mobile data unexpectedly. Users can navigate to offline map settings via the profile photo menu, then the gear icon, to disable auto-updates and restrict downloads to Wi-Fi only.

These adjustments allow users to maintain Google Maps' core navigation functionality while significantly reducing the app's data collection footprint and battery consumption.
