# Map: Top People From Each Bay Area City, According to Wikipedia Views

**Source**: https://www.sfchronicle.com/projects/2026/wikipedia-top-100-map/
**Date**: 2026-09-07
**Author**: Hanna Zakharenko and Emma Stiefel, San Francisco Chronicle
**Keywords**: interactive map, Wikipedia, Bay Area, data visualization, data journalism, Wikidata, cultural mapping, geographic data

## Elevator pitch
The San Francisco Chronicle built an interactive map showing the most-viewed Wikipedia person from every Bay Area city, using Wikimedia API pageview data spanning August 2021 to August 2026 to reveal the hometown heroes of each locality.

## Takeaways
- The Chronicle mapped the most-viewed Wikipedia person from every Bay Area city and town
- Data was collected using the Wikidata Query Service to retrieve Bay Area cities and match them to Wikipedia "people from" pages
- Pageview data was gathered via the Wikimedia API from August 27, 2021 to August 27, 2026
- ChatGPT was used to add links for about two dozen towns whose lists were not on Wikipedia's California page
- The map is interactive, allowing users to click and drag to explore and see who tops each location
- The project combines geographic data with cultural data to create a data journalism visualization

## Synthesis
The San Francisco Chronicle created an interactive map that reveals the most-viewed Wikipedia person from each Bay Area city, based on pageview data from August 2021 to August 2026. The project uses the Wikidata Query Service to retrieve a list of every Bay Area city or town, then matches locations to Wikipedia's "people from" pages to identify notable individuals from each place.

The methodology involved using the Wikimedia API to gather pageviews for each Wikipedia page linked on a "people from" page over a five-year period. The Chronicle manually verified that the most-viewed page for each location was indeed a person from that town. ChatGPT was used to add links for approximately two dozen towns whose lists were not included on Wikipedia's California people page, bridging gaps in the crowdsourced data.

The interactive map allows users to click and drag to explore the Bay Area, discovering the top Wikipedia person for each city. The project represents a creative intersection of geographic mapping, data journalism, and cultural data, using Wikipedia pageviews as a proxy for public interest in notable individuals from specific locations.
