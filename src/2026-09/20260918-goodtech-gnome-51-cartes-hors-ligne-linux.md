# GNOME 51 : les cartes hors ligne débarquent sur le bureau Linux

**Source**: https://goodtech.info/gnome-51-cartes-hors-ligne-mutter-bureau-linux/
**Date**: 2026-09-18
**Author**: GoodTech.info
**Keywords**: GNOME 51, GNOME Maps, offline maps, Linux, open source, OpenStreetMap, navigation, privacy, Mutter, Flatpak

## Elevator pitch
GNOME 51 ("A Coruña") brings offline map downloads to GNOME Maps for the first time, allowing Linux users to navigate without internet or ad tracking, alongside real-time transit info, an improved file manager, and the Bazaar app store joining GNOME Circle.

## Takeaways
- GNOME Maps now supports downloading entire regions for offline navigation — no cellular connection or location data sent to remote servers
- A storage management interface lets users control disk space used by cached map tiles and purge unused regions
- Transit module adds real-time delay alerts, platform/quai numbers, and walking time between connections
- GNOME Calendar integrates with Maps for one-tap itinerary calculation from event locations
- File manager (Nautilus) gains visual drag-and-drop count badge, smart file selection after duplication, and faster network directory reloading
- Mutter compositor gets frame scheduling rewrite to eliminate micro-stuttering under CPU load; legacy NVIDIA drivers removed in favor of modern standardized graphics interfaces
- SVG vector cursors replace bitmap cursors for sharp rendering on high-DPI displays
- Bazaar Flatpak app store joins GNOME Circle label alongside Bobby (SQLite browser) and Tally (counter manager)

## Synthesis
GNOME 51's headline feature — offline maps in GNOME Maps — closes a historic gap for Linux desktop users who relied on online mapping services. The release positions GNOME as a privacy-respecting alternative for mobile Linux users, with the Maps app using OpenStreetMap data cached locally. Available now on Arch Linux and openSUSE Tumbleweed, and coming to Ubuntu 26.10 and Fedora 45 this autumn.
