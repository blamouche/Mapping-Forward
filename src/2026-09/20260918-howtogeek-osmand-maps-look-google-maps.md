# How I made OsmAnd Maps look and feel more like Google Maps

**Source**: https://www.howtogeek.com/how-i-made-osmand-maps-feel-more-like-google-maps/
**Date**: 2026-09-18
**Author**: Joe Fedewa / How-To Geek
**Keywords**: OsmAnd, Google Maps, open source, map styling, Android, navigation, OpenStreetMap, customization, rendering style

## Elevator pitch
A How-To Geek writer details how to transform OsmAnd Maps — a powerful but visually unpolished open-source navigation app — into a Google Maps lookalike using custom rendering styles and UI tweaks, making the transition from Google's ecosystem more palatable.

## Takeaways
- OsmAnd supports custom map rendering styles via OSF files; a GitHub repository by "FilipBB" offers 25+ custom styles including two Google Maps-inspired looks ("Classic Web Map" and "Modern Web Map")
- Importing styles: Maps & Resources > Local tab > Rendering style > Three-dot menu > Import, then apply via Configure map > Map style
- Different styles can be applied for different navigation modes (driving, walking, cycling)
- UI tweaks include adjusting button placement, map orientation settings, and speed display preferences to match Google Maps conventions
- OsmAnd uses OpenStreetMap data and works fully offline, making it a privacy-focused alternative
- The article acknowledges OsmAnd's learning curve but argues that visual customization lowers the barrier to switching

## Synthesis
This practical guide addresses a common pain point for users considering open-source mapping alternatives: OsmAnd's functionality is strong but its default appearance is off-putting. By leveraging the app's deep customization system — rendering styles, UI configuration, and per-mode settings — the author demonstrates that OsmAnd can be made visually familiar enough for Google Maps users to adopt, combining Google-like aesthetics with OsmAnd's offline-first, OpenStreetMap-powered privacy advantages.
